## 📋 엑셀 파일 구조

### 헤더 (1행)
| 측정일시 | 이산화탄소<br>(CO2, ppm) | 초미세먼지<br>(PM2.5, μg/m³) | 미세먼지<br>(PM10, μg/m³) | 유기화합물<br>(VOC, ppb) | 포름알데히드<br>(μg/m³) | 일산화탄소<br>(CO, ppm) | 온도(°C) | 습도(%) |
|----------|-------------------------|----------------------------|-------------------------|----------------------|---------------------|---------------------|---------|---------|

### 데이터 형식
- **측정일시**: ISO 8601 형식 (예: `2026-01-11T17:24:35`)
- **수치 데이터**: 정수 또는 소수점 1자리
- **누락 데이터**: `-` 표시

### 특수 처리
- **포름알데히드**: PLC 값을 10으로 나눈 값 (소수점 1자리)
  - 예: PLC 값 156 → 엑셀 15.6

## 🔄 작동 방식

### 1. 초기 실행
```
[엑셀 기록] Loop started - interval: 5분 (공기질 데이터 누적)
[엑셀 기록] 새 파일 생성: 공기질데이터.xlsx
[엑셀 기록] 초기화 완료
```

- 파일이 없으면 헤더와 함께 새로 생성
- 파일이 있으면 기존 데이터 유지

### 2. 데이터 추가 (5분마다)
```
[엑셀 기록] ✅ 데이터 추가 완료 (행: 2, 시간: 2026-01-11T17:24:35)
[엑셀 기록] ✅ 데이터 추가 완료 (행: 3, 시간: 2026-01-11T17:29:35)
...
```

- DB에서 최신 데이터 조회
- 중복 방지: 같은 시간대 데이터는 건너뛰기
- 엑셀 파일 끝에 새 행 추가

### 3. 에러 처리
```
[엑셀 기록] ❌ DB 오류: database is locked
[엑셀 기록] ❌ 엑셀 쓰기 오류: Permission denied
```

- DB 락, 파일 접근 오류 등 자동 처리
- 1분 대기 후 재시도

## 💡 사용 팁

### 1. 엑셀 파일 열기
- **주의**: 파일이 열려 있는 동안에는 새 데이터가 기록되지 않습니다!
- **해결**: 파일 닫기 → 자동 기록 재개

### 2. 데이터 백업
```powershell
# 백업 폴더 생성
New-Item -ItemType Directory -Path "백업" -Force

# 파일 복사 (날짜 포함)
$date = Get-Date -Format "yyyyMMdd_HHmmss"
Copy-Item "대정서초 공기질.xlsx" "백업/대정서초_공기질_$date.xlsx"
```

### 3. 데이터 분석
- **일일 통계**: 피벗 테이블로 날짜별 평균/최대/최소 계산
- **시간대별 분석**: 차트로 시계열 데이터 시각화
- **경향 분석**: 추세선으로 장기 변화 파악

### 4. 파일 크기 관리
- **예상 크기**: 하루 288개 행 (5분 × 288 = 1440분)
- **월간 약**: 8,640개 행 → 약 1~2MB
- **연간 약**: 105,120개 행 → 약 12~24MB

### 5. 수동 조작
```python
# 엑셀 파일 읽기
import pandas as pd
df = pd.read_excel("공기질데이터.xlsx")

# 데이터 필터링 (특정 날짜)
df['측정일시'] = pd.to_datetime(df['측정일시'])
today_data = df[df['측정일시'].dt.date == pd.Timestamp.today().date()]

# 통계 계산
print(today_data.describe())
```

## 🛠️ 문제 해결

### 문제 1: 데이터가 추가되지 않음
**증상**: 5분이 지나도 새 행이 추가되지 않음

**확인 사항**:
1. 백엔드 서버 실행 확인
2. 로그 확인: `[엑셀 기록]` 메시지
3. 엑셀 파일이 다른 프로그램에서 열려 있는지 확인

**해결 방법**:
```powershell
# 엑셀 파일을 사용 중인 프로세스 종료
Get-Process | Where-Object {$_.MainWindowTitle -like "*공기질데이터*"} | Stop-Process
```

### 문제 2: 파일이 손상됨
**증상**: 엑셀 파일을 열 수 없음

**해결 방법**:
1. 백업 파일 복원
2. 파일 삭제 → 서버 재시작 (자동 재생성)

```powershell
# 파일 삭제
Remove-Item "공기질데이터.xlsx"

# 서버 재시작 (5분 후 새 파일 생성됨)
```

### 문제 3: 중복 데이터
**증상**: 같은 시간대 데이터가 여러 번 기록됨

**원인**: 시스템 시간 변경 또는 DB 롤백

**해결 방법**:
1. 엑셀에서 중복 행 수동 삭제
2. 또는 Python으로 중복 제거:

```python
import pandas as pd

# 엑셀 읽기
df = pd.read_excel("공기질데이터.xlsx")

# 중복 제거 (측정일시 기준)
df_unique = df.drop_duplicates(subset=['측정일시'], keep='first')

# 저장
df_unique.to_excel("공기질데이터_중복제거.xlsx", index=False)
```
