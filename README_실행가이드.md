# 🏭 PLC 공기질 모니터링 시스템 - 실행 가이드

> **PLC + AI + UI 통합 모니터링 시스템**  
> Modbus TCP를 통한 실시간 센서 데이터 수집 + Ollama AI 분석 + React 대시보드

---

## 🚀 빠른 시작 (가장 간단!)

### ✅ 실행하기
```
시작.bat 더블클릭
```

### ✅ 종료하기
```
종료.bat 더블클릭
```

**끝!** 이것만 알면 됩니다! 😊

---

## 📋 시스템 구성

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  PLC (192.168.250.120)                                 │
│    ↓ Modbus TCP (포트 502)                             │
│  Python Bridge (포트 8000) - 센서 데이터 수집          │
│    ↓ WebSocket                                          │
│  Backend + AI (포트 3001) - 데이터 처리 + AI 분석      │
│    ↓ WebSocket                                          │
│  Frontend UI (포트 5173) - 실시간 대시보드             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## ⚙️ PLC 설정

### PLC IP 주소 변경
```yaml
파일 위치: plc_modbus_bridge/config.yaml

plc:
  ip: "192.168.250.120"  ← 이 부분 수정
  port: 502
```

### 센서 매핑 (Modbus Input Registers)

| 레지스터 | 센서 | 단위 | 설명 |
|----------|------|------|------|
| MW20 | CO2 | ppm | 이산화탄소 |
| MW21 | TVOC | ppb | 휘발성유기화합물 |
| MW23 | 습도 | % | 상대습도 ÷ 10 |
| MW24 | 온도 | °C | 온도 ÷ 10 |
| MW26 | PM2.5 | ㎍/m³ | 미세먼지 |
| MW27 | PM10 | ㎍/m³ | 초미세먼지 |

## 🤖 AI 기능

### Ollama AI 자동 분석
- **분석 주기**: 1분마다
- **기능**: 
  - 실시간 공기질 상태 판정
  - 과거 패턴 학습 기반 예측
  - 조리사 행동 지침 생성
- **모델**: gemma2:2b (config.yaml에서 변경 가능)

### AI 설정 변경
```yaml
파일 위치: plc_modbus_bridge/config.yaml

ollama:
  url: "http://127.0.0.1:11434/api/generate"
  model: "gemma2:2b"
  alert_interval_sec: 60  # AI 분석 주기(초)
```

## ❓ 문제 해결

### ❌ "npm을 찾을 수 없습니다"
**해결**: PowerShell 대신 CMD 사용
```cmd
Win + R → cmd → 시작.bat 경로로 이동 → 실행
```

### ❌ "포트가 이미 사용 중"
**해결**: 
1. `종료.bat` 실행
2. 1-2초 대기
3. `시작.bat` 다시 실행

### ❌ PLC 연결 실패
**확인 사항**:
- [ ] PLC IP 주소 확인 (192.168.250.120)
- [ ] PLC와 PC 네트워크 연결 확인
- [ ] PLC Modbus TCP 활성화 확인
- [ ] 방화벽 설정 확인

**로그 확인**:
```
PLC Bridge 터미널 창에서 연결 상태 확인
"Connected to PLC" 메시지가 있으면 정상
```

### ❌ AI 분석이 작동하지 않음
**확인 사항**:
- [ ] Ollama가 설치되어 있는지 확인
- [ ] Ollama 서비스 실행 확인
- [ ] config.yaml의 Ollama URL 확인

**Ollama 설치**:
```bash
# https://ollama.ai 에서 다운로드
ollama pull gemma2:2b
```
