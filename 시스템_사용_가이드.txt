  🏭 PLC 공기질 모니터링 시스템 - 최종 사용 가이드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 시스템 구성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PLC (192.168.250.120)
    ↓ Modbus TCP
  Python Bridge (포트 8000) - 센서 데이터 수집
    ↓ WebSocket
  Backend + AI (포트 3001) - 데이터 분석 & Ollama AI
    ↓ WebSocket
  Frontend UI (포트 5173) - 실시간 대시보드


🚀 기본 사용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅ 시스템 시작:    시작.bat 더블클릭
  
  ✅ 시스템 종료:    종료.bat 더블클릭
  
  ✅ 문제 발생 시:   문제해결.bat 더블클릭


📊 접속 주소
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🌐 대시보드:      http://localhost:5173
  
  🔧 Backend API:   http://localhost:3001
  
  🔌 PLC Bridge:    http://localhost:8000/api/latest


🔧 문제 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ❌ PC 재부팅 후 PLC 연결 안 됨
     → 문제해결.bat 실행
     → 또는:
       1) 종료.bat 실행
       2) 네트워크 어댑터 재시작
       3) 시작.bat 실행

  ❌ 포트 충돌 오류
     → 종료.bat 실행 후 재시작

  ❌ 503 에러 계속 발생
     1) PLC 전원 확인
     2) PLC IP 확인 (192.168.250.120)
     3) 문제해결.bat 실행


📝 센서 데이터
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PLC 레지스터 → 센서:
  
  MW20  →  CO2 (이산화탄소, ppm)
  MW21  →  TVOC (휘발성유기화합물, ppb)
  MW23  →  습도 (%, ÷10)
  MW24  →  온도 (°C, ÷10)
  MW26  →  PM2.5 (미세먼지, ㎍/m³)
  MW27  →  PM10 (초미세먼지, ㎍/m³)

💡 주의사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
